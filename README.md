## Как запустить

Скачайте ZIP из релиза, распакуйте его целиком и запустите `RiverGuard.exe`. Установка .NET и Office не требуется. В архиве находится **одна версия**, без старых сборок, пользовательских проектов и тестовых данных. Кнопка GitHub **Code → Download ZIP** скачивает исходники, а не готовую программу.

В текущей ветке хранится только исходный код текущей версии в отдельной папке `versions/<версия>/`. Проверенные исходники предыдущих опубликованных версий доступны по их тегам, без дублирования всех версий в одном скачивании. Локальный архив старых сборок не загружается в репозиторий.

Новые проекты сохраняются в `Документы\RiverGuard\Проекты`; смена папки программы их не удаляет. Импортированные проекты остаются на исходных местах.

Порядок выпуска следующей версии: [PUBLISHING.md](PUBLISHING.md).

Исследовательская модель, не сертифицированный расчёт аварии ГТС. Обязательные уведомления о сторонних программных компонентах находятся в папке версии и в архиве программы.
