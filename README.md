# RiverGuard 1.4.1

**Автор приложения: Apdulium-beep.**

Локальная Windows-программа для исследования волны прорыва гидроузла.

## Запуск

При скачивании с GitHub готовые программы находятся в [Releases](https://github.com/Apdulium-beep/RiverGuard/releases), а не в архиве исходного кода. Скачайте ZIP нужной версии, распакуйте целиком и запустите `RiverGuard.exe`. Список сохранённых версий и оговорка об исторических исходниках: [VERSIONS.md](VERSIONS.md).

Откройте `Программа 1.4.1\RiverGuard.exe` или обновлённый ярлык `Запустить RiverGuard` в этой папке. Переносимая сборка Windows x64 не требует установки .NET, Python, Java, браузерного движка или доступа в интернет. При переносе используйте всю папку `Программа 1.4.1`.

Папки предыдущих версий сохранены. Закройте старое окно с сохранением нужных данных и запустите обновлённый ярлык. Формат проектов совместим.

## Быстрый старт

1. На стартовом экране выберите «Импорт проекта», «Создать новый проект» или откройте карточку справа.
2. При создании задайте название и один из четырёх механизмов: заданный проран, перелив через гребень, аварийное открытие затвора или круглое отверстие в теле плотины. Можно начать с демонстрационной геометрии или с пустого списка створов. Проект автоматически сохраняется в `Документы\RiverGuard\Проекты`.
3. Проверьте общие исходные данные и специфические поля выбранного механизма. При переливе поля формирования прорана отсутствуют.

В расчётной форме нет повторного ввода названия и выбора механизма. Для изменения названия используйте «Переименовать» в обзоре проекта, затем Ctrl+S.
4. В «Створы и рельеф» задайте глубины, ширины, коэффициенты Маннинга и горизонтали обоих берегов.
5. Нажмите F5 или «Рассчитать сценарий». Расчёт можно остановить.
6. В «Анализ и графики» выберите створ и нужную величину. Курсор показывает значения.
7. В разделе «Отчёт и экспорт» выберите XLSX, ODS, DOCX, HTML, CSV, JSON, RTF, TXT, Markdown, XML, PNG или ZIP со всем комплектом. XLSX и ODS создаются без установленного Excel.

Для PDF: экспортируйте HTML, откройте его в браузере и выберите «Печать → Сохранить как PDF».

Горячие клавиши: `Ctrl+S` — сохранить проект, `Ctrl+O` — открыть, `F5` — расчёт. В таблицах доступны Enter и Tab.

## Возможности

- Стартовый экран с библиотекой проектов, импортом и мастером создания.
- Кнопка удаления справа на карточке при наведении или фокусе клавиатуры: после подтверждения файл перемещается в корзину Windows. Для импортированного проекта удаляется оригинальный файл на исходном месте. Недоступные записи также можно удалить; удаление активного проекта закрывает его и отбрасывает несохранённые изменения после предупреждения.
- Книги XLSX и ODS с отдельными листами исходных данных, геометрии, результатов, зон, изодат, временных рядов и диагностики. Числа сохраняются числовыми ячейками, не формулами или строками.
- Каталог из 33 наборов исходных условий двух поддерживаемых механизмов: поиск, категории и независимые копии.
- Тёмный интерфейс WPF с адаптивными графиками, плавными переходами страниц и состоянием выполнения.
- Воспроизведение волны во времени: ползунок, маркер на графике и анимированное изменение уровня в морфостворе.
- Независимые расчётные модули на C#; операции выполняются вне UI-потока.
- Заданный проран с линейным раскрытием и перелив через неподвижный гребень без формирования прорана.
- Аварийное открытие прямоугольного затвора: ширина, максимальная высота и время подъёма; аналитическое интегрирование напора по открытой площади.
- Круглый дефект постоянного диаметра: нижняя отметка и диаметр; учёт свободного, частично погружённого и затопленного отверстия без модели роста дефекта.
- Расчётный гидрограф прорана и баланс водохранилища.
- Асимметричные русла и кусочно-линейные береговые горизонтали.
- Глубины, уровни, расходы, скорости, времена прихода и гребня по створам. Вклад аварии определяется относительно отдельного безаварийного расчёта.
- Сценарные границы пойменного затопления, пороги глубин 1,5 и 3 м.
- Изодаты глубины с оценкой распределения скорости и времени осушения.
- Проверка исходных данных, невязка водного баланса и предупреждения.
- Переносимые проекты `.riverguard`, недавние проекты, сохранение последней сессии.
- Word-отчёт с исходными данными, таблицами, изображениями графиков и ограничениями модели.
- Экспорт не смешивает изменённые входные данные с предыдущими результатами: используется снимок расчёта.

## Важно

**Это исследовательская модель, а не сертифицированный инженерный расчёт последствий аварии ГТС.** Программа не должна использоваться самостоятельно для реальных решений об эвакуации, проектирования защиты или утверждения нормативных границ.

Результаты вычисляются расчётным ядром. Встроенные примеры не являются подтверждёнными моделями реальных объектов. Авторство приложения не распространяется на сторонние библиотеки; обязательные уведомления сохранены в `THIRD_PARTY_NOTICES.txt`.

Подробности: `Документация\Модель.md` и раздел «Модель и ограничения» в программе.

## Сборка из исходников

Требуется Windows и .NET SDK 8 или новее.

```powershell
dotnet build RiverGuard.sln -c Release
dotnet run --project RiverGuard.Tests -c Release
dotnet publish RiverGuard.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o "Программа 1.4.1"
```

Для проверки интерфейса и экспорта запустите собранное приложение с `--smoke-test`. Оно выполнит короткий расчёт, создаст контрольные отчёты и изображения в своей папке `SmokeTest` и завершится.

Полная проверка сценариев:

```powershell
dotnet run --project RiverGuard.Tests -c Release -- --catalog-tests
```

Описание вариантов и неподдерживаемых механизмов: `Документация\Каталог сценариев.md`.

Работа со стартовым экраном и различия форм: `Документация\Проекты и сценарии.md`.
