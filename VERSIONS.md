# Сохранённые версии RiverGuard

Готовые переносимые сборки Windows x64 публикуются отдельными ZIP-архивами в GitHub Releases. Распакуйте архив целиком и запустите `RiverGuard.exe`. Установка .NET не требуется.

Автор приложения: **Apdulium-beep**. Текущая версия — **1.4.1**.

| Версия | Основные изменения |
| --- | --- |
| 1.0.0 | Первоначальная версия: расчёт, геометрия, графики, сохранение проектов и отчёты. |
| 1.1.0 | Каталог из 33 наборов исходных условий. |
| 1.2.0 | Стартовый экран, библиотека проектов, мастер создания, адаптация прорана и перелива. |
| 1.2.1 | Убраны повторные редакторы названия и механизма; отдельное переименование. |
| 1.3.0 | Удаление проектов в корзину и расширенный экспорт, включая XLSX и ODS. |
| 1.4.0 | Открытие прямоугольного затвора и круглое отверстие: всего четыре механизма. |
| 1.4.1 | Автор приложения указан как Apdulium-beep; обновлено оформление интерфейса, отчётов и документации. |

## Исходники исторических версий

Отдельные снимки исходного кода старых версий до первоначального импорта не сохранялись. Текущий исходный код — 1.4.1; исходный код 1.4 сохранён первоначальным импортом. Автоматические ссылки GitHub «Source code» у релизов 1.0–1.3 указывают на импорт 1.4, а не на восстановленные старые исходники. Для запуска конкретной старой версии используйте приложенный архив `RiverGuard-<версия>-win-x64.zip`. Старые EXE не переписывались; прежние тексты внутри них могут сохраняться.

Архивы не включают пользовательские проекты, учебные материалы, журналы и тестовое хранилище. Для проверки целостности к каждому релизу приложен SHA256.

Модель исследовательская, не сертифицированный расчёт аварии ГТС. Старые сборки могут содержать ограничения, устранённые в новых версиях; для текущей работы рекомендуется 1.4.
