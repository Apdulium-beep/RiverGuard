# Сохранённые версии RiverGuard

В GitHub Releases доступна только актуальная переносимая сборка **1.4.1** для Windows x64. Старые релизы и их вложения удалены с GitHub; локальные архивы сохранены. Распакуйте архив целиком и запустите `RiverGuard.exe`. Установка .NET не требуется.

Автор приложения: **Apdulium-beep**. Текущая версия — **1.4.1**.

| Версия | Основные изменения |
| --- | --- |
| 1.0.0 | Первоначальная версия: расчёт, геометрия, графики, сохранение проектов и отчёты. |
| 1.1.0 | Каталог из 33 наборов исходных условий. |
| 1.2.0 | Стартовый экран, библиотека проектов, мастер создания, адаптация прорана и перелива. |
| 1.2.1 | Убраны повторные редакторы названия и механизма; отдельное переименование. |
| 1.3.0 | Удаление проектов в корзину и расширенный экспорт, включая XLSX и ODS. |
| 1.4.0 | Открытие прямоугольного затвора и круглое отверстие: всего четыре механизма. |
| 1.4.1 | Автор приложения указан как Apdulium-beep; обновлено оформление интерфейса, отчётов и документации. |

## Исходники исторических версий

Отдельные снимки исходного кода старых версий до первоначального импорта не сохранялись. Текущий исходный код — 1.4.1; исходный код 1.4 сохранён первоначальным импортом. История Git и теги сохранены: теги 1.0–1.3 указывают на импорт 1.4, а не на восстановленные старые исходники. Для запуска старой сборки необходим её локальный архив. Старые EXE не переписывались; прежние тексты внутри них могут сохраняться.

Опубликованный архив не включает пользовательские проекты, учебные материалы, журналы и тестовое хранилище. Для проверки целостности к релизу приложен SHA256.

Модель исследовательская, не сертифицированный расчёт аварии ГТС. Старые сборки могут содержать ограничения, устранённые в новых версиях; для текущей работы рекомендуется 1.4.1.
