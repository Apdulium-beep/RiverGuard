# RiverGuard 1.4.1

Автор приложения: **Apdulium-beep**.

Обновлены раздел об авторе, стартовый экран, метаданные Windows, README и подписи отчётов. Из текущего интерфейса и документации убраны библиографические перечисления. Пример трёх створов получил нейтральное название без изменения числовых данных. Личные проекты не переименовываются и не переписываются.

Обязательные уведомления о сторонних программных компонентах сохранены в `THIRD_PARTY_NOTICES.txt`. Научные ограничения и описание расчётных методов сохранены. Авторство приложения не распространяется на сторонние библиотеки или общеизвестные методы.

Архивы старых сборок и прежние коммиты не переписывались: старые тексты могут оставаться внутри исторических EXE и в истории Git. На GitHub обновляются названия и описания релизов. Новая сборка публикуется отдельным релизом 1.4.1.
