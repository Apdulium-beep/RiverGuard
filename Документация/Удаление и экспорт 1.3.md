# Удаление проектов и экспорт · 1.3

## Удаление

При наведении на карточку справа появляется отдельная кнопка «Удалить». Она также доступна при фокусе клавиатуры внутри карточки. Нажатие не открывает проект. Подтверждение по умолчанию — «Нет»; оно показывает название и полный путь файла.

Файл отправляется в корзину Windows, затем удаляется из истории и индекса библиотеки. Если файл отсутствует, удаляется только запись. Повреждённые файлы можно удалять без открытия. Для импортированного проекта удаляется исходный файл, а не только ссылка на него: это отдельно оговорено в подтверждении. Если Windows не может выполнить операцию, выводится ошибка.

Удаление активного проекта закрывает рабочее пространство и отбрасывает несохранённые изменения после явного предупреждения. Программа не восстанавливает удалённый файл при закрытии. Отдельная ранее сохранённая копия автовосстановления не удаляется вместе с обычным проектом — её можно удалить собственной карточкой.

## Форматы

- **XLSX** — настоящая книга Excel, 13 листов: проект, параметры, геометрия, горизонтали, результаты, зоны, изодаты, гидрограф, уровень водохранилища, истории створов, диагностика, предупреждения и метод. Числовые значения — числовые ячейки; текст не исполняется как формулы. Заголовки выделены, верхняя строка закреплена.
- **ODS** — таблица OpenDocument с тем же набором листов, совместимая с LibreOffice и поддерживающими ODS редакторами.
- **DOCX и HTML** — существующие оформленные отчёты с графиками.
- **TXT, Markdown, RTF** — текстовые отчёты с таблицами, без встроенных графиков. RTF использует Unicode-последовательности для кириллицы.
- **XML** — структурированный табличный отчёт с явными типами чисел, текста и неопределённых событий.
- **CSV, JSON, PNG** — существующие таблицы, полный снимок результатов и изображение выбранного графика.
- **ZIP** — все отчёты и три графика PNG одним архивом. PDF в архив не включается.
- **PDF** — через экспорт HTML и команду браузера «Печать → Сохранить как PDF», не прямой PDF-экспорт.

Новые форматы экспортируются во временный файл рядом с выбранным назначением и заменяют существующий файл только после успешной генерации. Для XLSX, ODS и ZIP установка Office не требуется. Экспорт использует исходные данные выполненного расчёта, не подменяет их изменёнными входными значениями. Неопределённое время события не превращается в ноль.

## Проверки

Проверки рабочего процесса используют изолированную папку, не пользовательские проекты. Проверяются удаление тестового файла, очистка индексов, сохранность соседнего файла, удаление недоступных/повреждённых записей и закрытие активного проекта без повторного создания файла. Для новых форматов проверяются генерация и перезапись, схема XLSX OpenXML, типы числовых ячеек, отсутствие формул, структура ODS, синтаксис XML, сигнатура RTF, таблицы Markdown и состав ZIP. Артефакты: `Проверка интерфейса 1.3`.
