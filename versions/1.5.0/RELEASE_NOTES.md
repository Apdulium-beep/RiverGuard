# RiverGuard 1.5.0

Автор приложения: **Apdulium-beep**.

## Обновления внутри программы

- При запуске RiverGuard в фоне проверяет последний стабильный релиз GitHub.
- Если версия новее, предлагает **«Обновить и перезапустить»** или **«Позже»**.
- При согласии скачивает комплект, проверяет SHA256, состав ZIP и номер EXE, устанавливает отдельно и перезапускается после обычного запроса сохранения проекта.
- Загрузку можно отменить. Без интернета приложение продолжает работать.
- Ручная проверка — на стартовом экране и в разделе «Модель и ограничения».
- Пользовательские проекты и прежняя сборка не перезаписываются. Права администратора не требуются.

**Версию 1.5.0 необходимо запустить один раз:** прежняя 1.4.1 ещё не умеет обновляться автоматически. Дальше обновления будут предлагаться самой программой.

Windows x64: распакуйте весь ZIP и запустите RiverGuard.exe. Установка .NET и Office не требуется. SHA256 приложен.

[Исходники и документация именно этой версии](https://github.com/Apdulium-beep/RiverGuard/tree/v1.5.0/versions/1.5.0). В комплект не входят личные проекты и тестовые хранилища. Проверки: 255 — ядро, 87 — прежний рабочий процесс, 47 — механизм обновления. Новые проверки используют изолированные сетевые ответы без запуска пользовательских программ.

Обязательные лицензии компонентов сохранены. Модель исследовательская, не сертифицированный инженерный расчёт. Проверка контрольной суммы не является независимой цифровой подписью издателя.
