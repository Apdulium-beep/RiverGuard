# RiverGuard 1.6.0

**Автор приложения: Apdulium-beep.**

## Запуск

[Скачать Windows x64](https://github.com/Apdulium-beep/RiverGuard/releases/tag/v1.6.0). Распакуйте ZIP целиком и запустите `RiverGuard.exe`. Установка .NET и Office не требуется. Права администратора не нужны. Подробности: [инструкция переносимого запуска](docs/launch.md); эта же инструкция встроена в стартовый экран.

Установление бытового течения до аварии, согласованные времена волны, связь уровня и объёма, альтернативный ввод ширины через долю длины плотины и отдельное дно НБ. Новый книжный DOCX, плановая схема зон, история запусков со сравнением и клавиатурный ввод. Формат проекта SchemaVersion=1 сохранён; новые поля необязательны. **Режим по методике «Волны» не реализован: полного алгоритма нет.** Подробности — [модель](docs/model.md) и [проверки/ограничения](docs/verification.md).

На компьютере разработчика готовая программа находится в `app/RiverGuard.exe`. Папка `app` не хранится в Git: готовая сборка доступна отдельным вложением релиза, без повторного хранения большого EXE в истории исходников.

## Возможности

- Автоматическая проверка обновлений по умолчанию выключена; её можно включить в сведениях о модели. Ручная проверка сохранена. Обновление по согласию: SHA256, проверка ZIP/EXE, отдельная установка, сохранение проекта и перезапуск.

- Стартовый экран с созданием, импортом и библиотекой проектов.
- Четыре механизма: заданный проран, перелив, открытие прямоугольного затвора и круглое отверстие.
- Адаптация расчётных полей, графиков и отчётов к выбранному механизму.
- Створы, береговая геометрия, расчётный баланс, графики и воспроизведение времени.
- DOCX в книжной ориентации: исполнитель, данные гидроузла/створов, результаты, изодаты, скорости спада, зоны, метод и нумерованные рисунки. Графики всех створов и схема входят в отчёт.
- Схема ВЗМ/ВКЗМ/КР и эвакуации: экран, PNG, DOCX, HTML, ZIP; это схема, не ГИС-карта. Пороги настраиваются, альтернативный критерий глубины И скорости по умолчанию выключен.
- История выполненных, отменённых и ошибочных запусков в проекте; сравнение и перенос входных данных в новый расчёт без перезаписи исходного.
- Enter/Shift+Enter, создание строк таблиц, выделение поля при фокусе; три знака в представлении без округления внутренних данных.
- Переименование проекта; удаление в корзину после подтверждения.
- XLSX, ODS, DOCX, HTML, CSV, JSON, RTF, TXT, Markdown, XML, PNG и ZIP. PDF — через печать HTML в браузере.

## Сборка

Windows, .NET SDK 8 или новее. Команды выполняются из этой папки:

```powershell
dotnet build src/RiverGuard.sln -c Release
dotnet run --project src/RiverGuard.Tests -c Release -- --stage1-tests --stage2-tests --catalog-tests --catalog-report docs/core-checks.json --stage1-report docs/stage1-results.json
dotnet publish src/RiverGuard.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o app
```

Проверка интерфейса: `app/RiverGuard.exe --smoke-test`. Проверки используют изолированное хранилище, не пользовательские проекты.

[Как устроено автоматическое обновление](docs/updates.md). При проверке передаются только запрос к GitHub и номер приложения в User-Agent, не исходные данные проекта. Требуется публичный релиз: пароли и токены GitHub в программу не встраиваются.

Модель исследовательская, не предназначена для самостоятельных реальных решений об эвакуации. Авторство приложения не распространяется на сторонние библиотеки и общеизвестные математические методы.

**Ограничение проверки переносимости:** отдельные чистые Windows 10/11 без установленного SDK/Office не испытаны. Проверен локальный запуск без повышения прав; self-contained сборка дополнительно проверяется с недоступным общим .NET runtime. Совпадение с «Волной» и нормативное соответствие не заявляются.
