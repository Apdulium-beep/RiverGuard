# Запуск RiverGuard 1.6.0 на другом компьютере

Автор приложения: **Apdulium-beep**.

1. Скачайте `RiverGuard-1.6.0-win-x64.zip` из релиза GitHub `Apdulium-beep/RiverGuard` и файл `RiverGuard-1.6.0-SHA256.txt`.
2. Проверьте SHA256 архива (`Get-FileHash .\RiverGuard-1.6.0-win-x64.zip -Algorithm SHA256` в PowerShell). Сумма подтверждает целостность относительно опубликованного значения, не заменяет цифровую подпись издателя.
3. Распакуйте ZIP **целиком** в папку, доступную вашему пользователю. Внутри `RiverGuard-1.6.0` запустите `RiverGuard.exe`. Не запускайте EXE внутри ZIP и не удаляйте `THIRD_PARTY_NOTICES.txt`.
4. Отдельная установка .NET и Office не нужна: сборка self-contained, DOCX/XLSX создаются программно. Администратор и установка в Program Files не требуются. Не отключайте антивирус целиком при предупреждении Windows; сначала проверьте источник файла.
5. На стартовом экране создайте проект либо импортируйте старый `.riverguard`. Новые проекты находятся в `Документы\RiverGuard\Проекты`, импортированные остаются по исходному пути. Сохраняйте несохранённые проекты через Ctrl+S.
6. F5 запускает расчёт, Enter/Shift+Enter перемещают по полям, Ctrl+Enter вставляет строку заметок. В таблице Enter в конце последней строки создаёт новую. Числа при просмотре имеют три знака, в редакторе ячейки — полную точность.
7. Существующий проект сохраняется автоматически после попытки расчёта вместе с историей. В ещё не сохранённом проекте история остаётся в памяти до Ctrl+S. Не редактируйте новый проект прежним EXE: старая версия может не сохранить новые поля/историю.
8. В анализе доступны временные графики и «Схема зон в плане». DOCX — книжный отчёт со всеми створами и рисунками. Для PDF экспортируйте HTML и используйте печать браузера.
9. Обновления вручную — кнопкой на стартовом экране. Фоновая проверка по умолчанию выключена; её можно включить в сведениях о модели. Обновления устанавливаются отдельно и не удаляют прежний EXE или проекты.

Для реального объекта подтвердите геометрию, отдельное дно НБ и поддерживаемый бытовой приток. Демонстрационные данные не являются обмерами реальной плотины. Программа не воспроизводит методику «Волны», не сертифицирована и не предназначена для решений об эвакуации.

**Предел испытаний:** проверен локальный запуск Windows x64 без повышения прав. Self-contained вариант дополнительно проверяется с недоступным общим .NET runtime. Отдельные чистые Windows 10 и Windows 11 без SDK/Office пока не испытаны — такие среды недоступны. Это ограничение не скрывается и не подменяется проверкой на компьютере разработки.
