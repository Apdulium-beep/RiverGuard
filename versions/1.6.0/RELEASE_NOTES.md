# RiverGuard 1.6.0

Автор приложения: **Apdulium-beep**.

## Расчёт RG-1D

- Установление бытового течения до аварии с постоянным притоком и отказом при неустановившемся режиме.
- Одинаковый подготовленный снимок для аварийного и безаварийного расчётов; бытовой приток включён в баланс.
- Гребень и спад определяются по одной аварийной добавке; максимум полного уровня хранится отдельно.
- Необязательная связь уровня/объёма и отдельная отметка дна нижнего бьефа; новые поля сохраняют совместимость SchemaVersion=1.
- Альтернативная ширина прорана Eр·Bв; Eр — доля длины плотины, не универсальная степень разрушения сооружения.
- Незавершённый спад не выдумывается и не переставляется механически: выводится «не определено» с предупреждением. Осушение изодат определяется по индивидуальным пересечениям уровня.
- На примере «Три створа» дрейф закрытого режима менее 0,033 % по глубине и 0,025 % по расходу за 3 ч; подъём уровня водохранилища на 1 м увеличивает Qmax на 13–20 %. Это регрессионная проверка, не инженерная валидация.

## Отчёт и зоны

- Книжный DOCX: нейтральный титул, исполнитель, исходные данные гидроузла и створов, результаты, изодаты, скорости спада, зоны/эвакуация, метод, последовательные подписи «Рисунок N».
- Графики всех створов и плановая схема ВЗМ/ВКЗМ/КР включаются в DOCX, HTML и ZIP; схема отдельно сохраняется в PNG. **Схема, не ГИС-карта.**
- Пороги зон настраиваются. По умолчанию глубины 0,000 / 1,500 / 3,000 м; альтернативная ВКЗМ «глубина ≥1,000 м И скорость ≥0,700 м/с» выключена. КР дополнительно ограничена приходом фронта в первый час от начала аварии. Это явно описанная сценарная трактовка, не заявление о нормативном соответствии.
- Расчётные величины отображаются с тремя знаками. Внутренние значения и числовые ячейки книг не округляются.

## Удобство и запуск

- Enter / Shift+Enter, выделение поля при фокусе, создание следующей строки таблицы; сохранены F5 и Ctrl+S. Числовой редактор таблицы раскрывает полное значение без потери точности.
- История выполненных, отменённых и ошибочных попыток в проекте; сравнение двух запусков и перенос входных данных в новый расчёт. Старые проекты SchemaVersion 1 открываются; личные данные не мигрируются и не загружаются на GitHub.
- Автоматическая проверка обновлений **по умолчанию выключена**. Ручная кнопка и безопасное обновление по согласию сохранены; включение фоновой проверки — только явным выбором пользователя.
- Переносимая self-contained сборка Windows x64, без отдельной установки .NET/Office и без администратора. На стартовом экране встроена инструкция запуска.

## Проверки и ограничения

Проверки: **406 — ядро и каталог; 200 — рабочий процесс, экспорт, обновления и новые этапы**. Решение собирается без предупреждений и ошибок. DOCX/XLSX проверены OpenXML; отчёт дополнительно открыт и визуализирован Word, числовые ячейки прочитаны независимой библиотекой. Испытания используют изолированное хранилище и подставные сетевые ответы.

**Отдельные чистые Windows 10/11 без SDK/Office пока не испытаны:** среда недоступна. Проверен локальный запуск без повышения прав; self-contained EXE проверяется с недоступным общим runtime. Не выдаём это за испытание на чистой ОС.

**Второй режим «по методике / как в Волне» не добавлен:** полного воспроизводимого алгоритма нет. Расхождения с эталоном по скоростям и глубинам остаются существенными; результаты не подгонялись к 5 %. Полноценная сеточная/лабораторная валидация и нормативное соответствие не заявляются.

[Исходники, инструкция и протокол проверок](https://github.com/Apdulium-beep/RiverGuard/tree/v1.6.0/versions/1.6.0). В ZIP только текущая версия, README и обязательные уведомления; личных проектов и тестовых файлов нет. SHA256 приложен.

Обязательные лицензии компонентов сохранены. Модель исследовательская, не сертифицированный инженерный расчёт. Проверка контрольной суммы не является независимой цифровой подписью издателя.
