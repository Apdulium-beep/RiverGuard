# Настройки интерфейса RiverGuard 1.8.0

Кнопка **⚙ Настройки** доступна на стартовом экране и в верхней панели проекта.

- **Простой** интерфейс: шаги работы, объяснения терминов, меньше технических колонок. Начните с готового примера, затем заполните данные своего объекта.
- **Стандартный**: привычные разделы и поля.
- **Экспертный**: все колонки и техническая сводка результата.
- Темы: **Океан**, **Светлая**, **Графит**, **Лес**.
- Можно изменить размер основного текста, скрыть пошаговые пояснения или отключить анимацию переходов.

Изменения видны сразу. **Сохранить настройки** запоминает их для следующих запусков; **Отмена** или закрытие окна возвращает прежний вид. Настройки общие для приложения, а не часть проекта.

Скрытые поля сохраняют значения и продолжают участвовать в расчёте. Для их проверки переключитесь в стандартный или экспертный режим. Обязательные коэффициенты экспериментальной методики 1997 остаются видимыми всегда.

Темы не меняют формулы, исходные данные, историю и результаты. Оформление экспортируемых графиков и печатных схем не зависит от темы окна. Размер основного текста не масштабирует абсолютно все элементы интерфейса.

Автоматическая проверка обновлений по умолчанию выключена. Предварительный просмотр не запускает сетевую проверку. Сброс оформления не меняет выбор автоматических обновлений.

Простой интерфейс не заменяет знания гидравлики: примеры не являются данными вашего объекта, а успешное выполнение программы не подтверждает достоверность инженерного прогноза.
